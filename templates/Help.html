Conformance Manager is a calibration and service record management system. Use the sections below to understand each part of the application.

🏠 Home

Displays all active service records sorted by Next Service Date (soonest first). Use this view to quickly identify gauges approaching or past their service due date. Type in the Search box to instantly filter the table by any field.

➕ Add Tool

A three-step wizard for registering a new gauge and its initial service record in one flow.

  1. Manufacturer — Select an existing manufacturer or enter a name to create a new one.
  2. Model — Select an existing model for that manufacturer or add a new model with Size and End Size.
  3. Unit & Service — Set the location, gauge serial number, calibrated-by user, owner, certificate number, calibration date, last/next service dates, and post-condition.

The certificate number is auto-incremented. Check Override to enter a custom value.

🔩 Equipment

Manufacturers

Manage the list of gauge manufacturers. Each manufacturer has a name. Models are linked to a manufacturer, so add manufacturers before adding models. Use the Search box to filter the list by name.

Models

Manage gauge models. Each model belongs to a manufacturer and includes a name, Size, and End Size. Service records reference a model directly. Use the Search box to filter by any field.

Service

The central record of all calibration activity. Each service record captures: manufacturer, model, location, gauge serial number, technician (Calibrated By), owner, calibration date, certificate number, last/next service dates, and post-condition (New, Good, Poor, Bad). Records marked Bad are excluded from standard exports but included in the Damaged Units export. Use the Search box to filter across all columns.

⚙️ Administration

Locations

Manage facility locations (e.g. Facility-A, Facility-B, Facility-C). Locations are assigned to service records and to users. Default locations are seeded on first run.

Users

Manage calibration technicians. Each user has a name and an assigned location. Users appear as the Calibrated By person on service records.

📊 Data

Export

Four export options are available:

  • Full Export — All active service records plus the models list.
  • Service Only — Active service records (condition is not Bad).
  • Damaged Units — Service records with condition = Bad.
  • Backup — Raw export of all tables for archival.

All exports are formatted Excel (.xlsx) files with styled headers and auto-sized columns.

Import

Download the import template (CRIMan_Import.xlsx), fill in the sheets (Manufacturers, Models, Locations, Users, Service), then upload the file. Rows with matching IDs are updated; new IDs are inserted. Blank rows are skipped.

Data Normalization

Detects and merges duplicate records to keep the database clean. Two normalization passes are available and must be run in order:

  1. Normalize Manufacturers — Groups manufacturers that share the same name (case-insensitive). Keeps the record with the most linked models and remaps all md_mfr_id references before deleting the duplicates.
  2. Normalize Models — Only available after manufacturer duplicates are resolved. Groups models that share the same Name, Size, End Size, and Manufacturer. Keeps the record with the most linked service entries and remaps all srv_md_id references before deleting the duplicates.

The page displays summary cards showing how many duplicate groups exist. A confirmation prompt is shown before any merge is applied.

Schedule

Create scheduled report recipients. Each schedule has a name, description, email address, and a cron expression defining when it runs. Click Run Scheduler to immediately send the current service report to all configured recipients as an Excel attachment.

Tips

  • Click any column header marked with a sort indicator to sort the table by that column. Click again to reverse.
  • Use the Search box on Home, Manufacturers, Models, and Service to instantly filter rows — no page reload needed.
  • Add manufacturers and locations before adding models or users.
  • Certificate numbers are auto-incremented (0001, 0002 …). Use Override only when assigning a specific number.
  • Use the Import template to bulk-load data into a fresh installation.
  • Records with condition Bad remain in the database but are excluded from the Home view and standard exports.
  • Run Data Normalization after imports to merge any duplicate manufacturers or models introduced by bulk data.
  • The current database version is displayed in the top navigation bar next to the company logo.
